# LR7: QR Scanner App 📱

Простое Android-приложение для сканирования QR-кодов и идентификации определенных товаров. Разработано в рамках лабораторной работы №7.

## 📋 Описание
Приложение позволяет пользователю сканировать QR-коды с помощью камеры устройства. В зависимости от содержимого QR-кода, приложение отображает соответствующее изображение и название товара.

### Основной функционал:
1.  **Сканирование:** Использование библиотеки ZXing для считывания QR-кодов.
2.  **Обработка результатов:**
    *   Если QR-код содержит текст **"bread"** — показывает картинку хлеба и подпись "Свежий хлеб".
    *   Если QR-код содержит текст **"milk"** — показывает картинку молока и подпись "Домашнее молоко".
    *   Если QR-код содержит текст **"chocolate"** — показывает картинку шоколада и подпись "Молочный шоколад".
3.  **Обработка ошибок:** Если код не распознан, выводится сообщение "Неизвестный товар" и отображается сам считанный текст с иконкой предупреждения.

## 🛠 Технологии
*   **Язык:** Java
*   **SDK:** Android SDK
*   **UI:** XML (ConstraintLayout, CardView)
*   **Библиотеки:**
    *   [ZXing Android Embedded](https://github.com/journeyapps/zxing-android-embedded) — для реализации сканера штрих-кодов.

## 📂 Структура проекта
*   **MainActivity:** Стартовый экран с кнопкой "Сканировать QR-код".
*   **ResultActivity:** Экран результата, отображающий карточку с товаром.
*   **Resources:**
    *   `drawable/` — содержит изображения (`bread`, `milk`, `chocolate`).
    *   `values/strings.xml` — содержит текстовые ресурсы и информацию об авторе.

## 🚀 Как запустить
1.  Клонируйте репозиторий.
2.  Откройте проект в **Android Studio**.
3.  Дождитесь синхронизации Gradle.
4.  Убедитесь, что в `build.gradle` (Module: app) добавлена зависимость для ZXing:
    ```gradle
    implementation 'com.journeyapps:zxing-android-embedded:4.3.0'
    implementation 'com.google.zxing:core:3.4.1'
    ```
5.  Запустите приложение на реальном устройстве (для работы камеры) или эмуляторе (с эмуляцией камеры).
